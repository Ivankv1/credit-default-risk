# Credit Default Risk Prediction

## Описание
Проект по построению модели кредитного скоринга на данных Home Credit Default Risk.  
Задача — предсказать вероятность дефолта клиента.

## Основные результаты
- **ROC-AUC**: 0.7815
- **Brier Score** (после калибровки): 0.0662

## Что реализовано
- Полный разведочный анализ данных (EDA)
- Обработка аномалий и пропусков
- Feature Engineering (отношения сумм, возраст, стаж и др.)
- Агрегация данных из bureau и previous_application
- Обучение LightGBM
- Подбор гиперпараметров с помощью Optuna
- Интерпретация модели через SHAP
- Калибровка вероятностей (Isotonic Regression)

## Важные инсайты
- Наиболее сильные признаки: `EXT_SOURCE_1`, `EXT_SOURCE_2`, `EXT_SOURCE_3`
- Молодые клиенты и клиенты с небольшим стажем имеют существенно более высокий риск дефолта
- Созданные отношения (`CREDIT_ANNUITY_RATIO`, `ANNUITY_INCOME_RATIO` и др.) показали высокую важность
- Калибровка значительно улучшила качество вероятностных прогнозов
